Its global pipeline/route trial was deferred in favor of the combined [TABLES candidate](tables.md).** The read-only routed diagnostic found both mode and scale lookup cones still failing, so no SCALE-only global result is implied.

The actual Elastic placed path ends at `coefficients/admission/lookup_scale_reg[1]/D`: error/abort/state qualification feeds an eleven-level LUT/MUX read/hold tree, with 13.714 ns data delay and −3.723 ns slack at 10 ns. This identifies actual table lookup cones, rather than assuming every path ending near admission is packet RAM.

[Production source](../../fpga/experiments/cu66-v107-scale/cs88_admission_v91i2a.sv) is frozen at SHA-256 `1956b84f3253ae688674744cd68952e21d8404318b0f4f7b69cf13e1207abfb3`, based on HEADER `7a417f9a…`. Its 1,350×2 scale store becomes a common-clock TDP helper. External cache writes use logical port A; Q_FILL writes and FINISHED registered reads use logical B. Only a simultaneous same-address A write is suppressed, preserving the original later Q_FILL write priority. FINISHED read plus same-address A write returns old data. Q_FILL writes and reset/start/abort inhibit lookup updates; the previous output holds. Parser widths, 49,152-byte capacity, full 32-bit guards, error priority and cycle schedule stay unchanged.

The inferred implementation is **one RAMB18E1, TDP, width9/9, READ_FIRST/READ_FIRST, optional output registers 0/0**, with logical ports swapped by synthesis and a small registered hold mux. The physical B mode is not called NO_CHANGE: public hold behavior is established by the complete mapped primitive/hold-mux netlist. AMD's [7-series memory guide](https://docs.amd.com/api/khub/documents/9gZGbqBxtlKXxBfkBt~lAg/content) and [RAMB18E1 library definition](https://docs.amd.com/r/2024.2-English/ug953-vivado-7series-libraries/RAMB18E1) define the common-clock collision and mode assumptions. No explicit primitive or collision-warning suppression was needed.
