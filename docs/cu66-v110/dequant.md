It targets the measured FETCH group-index → quantizer/mux → combinational DSP → packed-output path described in [the pinned analysis](dequant-next.md). No timing gain or DSP register absorption has been measured.

The original coefficient/chroma/scale RF capture and complete original combinational quantizer/selection/product block remain byte-identical. Operands have no added reset; original public reset/abort output clearing, ID/error, ready/valid, bad/allzero fast exits, HOLD_TILE stalls and partial invalid output writes remain unchanged.
