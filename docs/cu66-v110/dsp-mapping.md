The RTL declares 192 operand bits: eight signed16 coefficients plus eight unsigned8 fully scaled/clamped quantizers. That is a source declaration count, not a count of retained physical slice flip-flops. AREG/BREG attributes count enabled stages inside each DSP primitive; they do not provide a complete register-bit or net-connectivity inventory.

In particular, **BREG=0 does not show that five lanes lost the logical operand-register boundary**. Quantizer state can remain outside a DSP in slice registers, be shared between equal functions, or be represented by an optimized equivalent. The source and already passed whole-body public-cycle checks establish the logical edge behavior. Determining the exact residual physical representation requires a per-cell register/pin connectivity inventory. None is emitted by this frozen recipe, so no exact remaining coefficient/quantizer slice-FF count or A/B operand-pin assignment is claimed.
