# Independent R3 Rice prefix-cut review

The proposed **parallel direct-rank load/take** rewrite is exact over the complete bounded arithmetic domain. It is a real source factoring opportunity in the selected native closure. Its physical effect still requires focused/full qualification and measurement: the measured endpoint is a quotient **clock enable**, whose required window/readiness/truncation dependencies remain.

The independently checked [R3 final route](../../experiments/python-gamebub-v110/native/20261108T141714174050Z/reports/route-setup-paths.rpt) launches from `cached_remaining_reg[5]` and ends at `quotient_reg[3]/CE`, slack −2.871 ns. Its 12.618-ns data path has 17 levels including three CARRY4s, 3.186 ns logic and 9.432 ns routing (74.751%). Launch fanout is four; most routed intermediate nets have fanout one through five, with 0.5–1.0-ns segments. Two optimized intermediate nets have fanouts 76 and 50, but the seventeen-level dependence is not established as a generic high-fanout problem. A blanket replication recommendation would lack causal evidence.

Let `w=min(remaining,15)`, `r=prefix_rank`, `z=min(w,r)` and `f=(r<w)`. For every `w,r` in 0–15:

- If `f`, then `z=r<=14`, so the old parallel `take_bits` is `r+1`.
- If not `f`, then `z=w`; both the ordinary old branch and its `z==15` case return `w`.
- Consequently `take_bits = f ? r+1 : w` is exact for **all** parallel PREFIX window/rank pairs, including unconsumed and empty windows.
- After the original nonempty, ready, nontruncated parallel branch reaches the quotient/suffix assignments, its guard implies `f || w==15`. If `f`, `z=r`; otherwise `w==15` and `r==15`, so again `z=r`. Therefore quotient may load `r` directly, and the suffix selector may use `r==15` in this guarded branch.

The standalone stdlib [review script](../../scripts/cu66-v110/prefix_review.py) independently exhausts 16,640 window/rank/available combinations, including 6,610 consuming nontruncated load cases. All unsigned32 remaining values are covered through the sixteen exact `min(remaining,15)` equivalence classes. This proof does not assume zero padding or inspect reservoir contents: every rank in 0–15 is enumerated. It does not establish formal four-state equivalence or reachability.

This cut removes the remaining-derived `zeros` clamp from selected quotient/suffix data and the redundant clamp inside parallel take arithmetic. It preserves the necessary `window`, `can_step`, truncation and accepted request/input priority dependencies. A changed shared data/CE factoring could improve the measured CE path, but this arithmetic proof alone does not show how many of its seventeen levels disappear or establish any nanosecond recovery.

The initially discussed **serial** fixed-bit rewrite is also a valid generic identity: in serial PREFIX, `take_bits==1` and `extracted=={63'd0,reservoir[63]}`. However, independently checking the authoritative R3 source card finds [actual V108 pipeline line 153](../../fpga/experiments/cu66-v108-capacity/br88_pipeline_v91h.sv#L153) ties `serial_mode=0`; actual FETCH ingress resets/captures that zero and the actual context forwards it to Rice. The optimized LUT alias `serial_reg_2` on the timing path is not evidence of a surviving serial branch. The serial-only rewrite therefore lacks a demonstrated native causal benefit for this closure and is not the supported final adaptive experiment.
