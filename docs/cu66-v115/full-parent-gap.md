## Exact disconnected interfaces

- **Endpoint and register map:** QSPI core transactions in the `0xE...` region become 12-bit core bus accesses. The current JPEG map is at `E0000000`: `+00` identity, `+04` protocol version, `+08` JPEG capability, `+0c` bytes remaining, `+10` state, `+14/+18/+1c/+20` frame metadata/CRC, `+24` start/abort/commit controls, and `+100` compressed JPEG bytes. Firmware uses this map. CS88 instead needs parallel packet metadata/start plus `in_valid/in_ready/in_data/in_last`; no CS88 register map or endpoint decoder joins them.
- **Storage and references:** CS88 requests tagged 128-bit scratch transactions and separately requests 512-bit reference tiles. [`moonshine_core.sv`](../../fpga/rtl/moonshine_core.sv) keeps compressed JPEG bytes in its own internal BRAM; [`moonshine_memory.sv`](../../fpga/rtl/moonshine_memory.sv) arbitrates 16-bit RGB565 writes and LCD line reads over SDRAM. No shared address space, allocator, arbiter, or reference-bank service connects these interfaces. See also [`moonshine_sdram.sv`](../../fpga/rtl/moonshine_sdram.sv), SHA `f1c3bfd6e41b0f2cae0a68e4bf37155a5914d2993dc27d22b9a052d3e9b0f26f`.
- **Color, C2/HUD, and publication:** CS88 emits provisional planar YCbCr. [`canonical_rgb565_v91k.sv`](../../fpga/experiments/cu66-v91k/rgb/canonical_rgb565_v91k.sv), SHA `2a0a10185ed328ad7228ec8cf809036fd29c7eddd3e5deb3ddb0e895d2787217`, converts a byte-addressed provisional frame but is separately simulated and has no commit input from the validator. The [`V91l validator`](../../fpga/experiments/cu66-v91l/cs88_validate_publish_v91l.sv), SHA `fab62dcdbcb9a2594917eac0eaf09a9eda1df8879e799ce38833ca678069d143`, provides C2 root, semantic HUD digest, seal, and abstract bank ownership. [`cs88_live_v91l.sv`](../../fpga/experiments/cu66-v91l-live/cs88_live_v91l.sv), SHA `c8d579aec574da8e9893bc922a9ffdcc12d18ffe5dd478349514db1c6fff50b8`, joins the earlier V91k producer to that validator through an ACK-coupled write/hash path; it is a simulation partition, not the V115 source-pinned production parent. HUD decoding/receipt preparation remains software. Validator bank IDs, `vblank`, `writes_drained`, and `scanout_drained` are not connected to Moonshine SDRAM ownership, `front_buffer/front_valid`, or LCD scanout.
- **Display path:** [`moonshine_lcd.sv`](../../fpga/rtl/moonshine_lcd.sv), SHA `f6ef8c7476860c4ccc0cda18f86a1a22c267521f81f9a21f71b4b9c153e9fb27`, scans 16-bit RGB565 line data; [`esp32_overlay.sv`](../../fpga/rtl/esp32_overlay.sv), SHA `19a63f9a99784def9d6f454f717eda10a311738d1bc32a16c44e70e5d6ba2ec5`, consumes separate overlay writes. ## First bounded custom simulation handoff

Start with a one-key-frame simulation driven at the real CS88 component byte-stream ports. This deliberately stops before QSPI, target firmware, or host negotiation.

1. Instantiate the source-pinned V115 CS88 composition with finite scratch and reference responders. Use explicit latency/backpressure, retain request identity until matching ACK, and cover abort, stale response, matching bus error, and clean retry.
2. Compare every canonical Y/Cb/Cr output tuple and committed planar byte with an independent pinned golden. Keep all tuples provisional until the C2 root, software-verified HUD receipt/payload, seal, producer completion, and physical write-ACK drain agree. Demonstrate that a corrupted byte and a mismatched ACK prevent commit and display.
3. After validator commit, convert only committed planes through the actual RGB565 converter. Add a finite explicit bank/address adapter and connect output to the existing SDRAM model and LCD line interface. Compare all 345,600 RGB565 pixels, require one matching frame presentation and zero scanout underruns.
4. Preserve strict compile/run commands, exact source/fixture/golden hashes, full ownership/error traces, and a single auditable PASS/FAIL receipt. Label the result one-frame simulated integration, not production-parent or hardware qualification.

The necessary new pieces are the test wrapper and finite CS88 memory/reference services, the commit-authorized bank/address connection, and the RGB565-to-Moonshine-memory/display connection. The later independent gate is a specified CS88 QSPI register/packet map plus endpoint/CDC and firmware/host support. The current JPEG qspi-study integration does not implement that gate.
