## Producer ownership and nonce budget

The actual producer is `fpga/experiments/cu66-v110-ready/cs88_coefficients_v91k.sv`. Its CHECK_ENTROPY branch at lines1192–1197 first rejects unsupported nonempty-plane entropy with error64, then evaluates a64-bit sum of the32-bit child nonce and three nonzero-plane predicates, rejecting overflow with error66. Its success branch also writes `producer_cell_cache=quant_cell(0,tile_cursor)`. This is a source-level hypothesis for the routed plane-block-to-cache-enable family, not a proven mapping of the critical chain to the nonce branch. The flattened STA names are insufficient to establish that Boolean attribution; a bounded checkpoint fan-in/primitive-equation analysis remains open. The candidate redundant-write and exact-budget changes must be tested independently before attributing any routed improvement.

Independently of that mapping hypothesis, first prove and remove the redundant CHECK_ENTROPY cache write: accepted start already sets plane, tile cursor and cache to zero at lines1173–1176, and ADMIT/CHECK_ENTROPY do not otherwise change them before that success branch. `quant_cell(0,0)` is zero. Removing that redundant assignment can eliminate an irrelevant deep condition from the cache CE without adding an edge or changing a private value. Retain the current all-cycle cache/geometry oracle and add the explicit accepted-start-to-CHECK ownership invariant. PREP_PLANE's legitimate nonempty-plane clear and later positional updates remain.

Then replace the wide nonce-budget sum with exact bounded arithmetic. Count the three nonzero planes into a two-bit `needed` value0–3. Overflow can only occur when `child_nonce[31:2]` is allones and the three-bit sum of `child_nonce[1:0]` plus `needed` exceeds3. This is equivalent to the original64-bit comparison for every32-bit nonce; it does not narrow plane-block fields or sum their block counts. The entropy64 rejection must retain priority over overflow66. Retain ALLOCATE's independent `child_nonce==0xffffffff` rejection and physical child-drain gates. Preserve the current nonce and anti-replay lifetime across warm reset; they are declaration-initialized state, not fields to clear when a prepared record is invalidated.

If ownership records are registered, capture the complete receipt owner, nonzero-plane mask, entropy decision and nonce snapshot only on the accepted ADMIT receipt edge. Never sample a partly parsed block count. Require the same frame/receipt epoch at consume and invalidate preparation on reset, abort, new command or older fault. Prefer existing edges; any extra validation edge must be declared and measured rather than hidden as a timing exception.

## Reuse the admission parser's existing owned mode extent

The actual admission source is `fpga/experiments/cu66-v116-admission/cs88_admission_v91i2a.sv`. HEADER_CHECK captures `mode_bytes=h32(36)` and `q_start=header_mode_start[31:0]` together at lines469–470. The existing header cache asserts the full35-bit `header_mode_start=128+{3'd0,h32(36)}` before consumption. Accepted headers also enforce mode bytes≤976.

MODE_BIT line495 currently compares `mode_cursor>=128+mode_bytes`; MODE_END line536 compares `mode_cursor!=128+mode_bytes` before resetting `active_index`. Reuse the already captured32-bit `q_start` as the mode-end bound in both places. Assert the owned identity `q_start==32'(128+mode_bytes)` throughout consumption. This removes live addition from the bound checks, rather than registering a late comparator output that might let an invalid byte or scan transition escape. Preserve the original bit-cache-zero check, error8 precedence, cursor updates, packet read addresses and exact32-bit wrapped source semantics. Do not narrow a public field because the successful header range is smaller.

Prepared-state benches must bind both the cached bound and its matching source owner; independently poking a mode byte count while leaving an unrelated old `q_start` cannot qualify the new architecture. Keep all original guards/goldens, add coherent preparation checks and retain malformed header/path cases. This existing-field substitution needs no added cycle if those ownership invariants hold.

## Remove physical response-tag logic from unrelated payload enables

The actual reconstruction source is `fpga/experiments/cu66-v118-reconstruct/cu66_reconstruct_stream_v91k.sv`, SHA256 `9caa5626404853d35cc0e39b9727ceeea60afe971916d9afe289edc5af25461c`. Its complete pending physical descriptor is compared at lines162–163, and `response_failure` at line169 gates the normal central FSM at line236. The residual writes at lines282–286 therefore inherit this tag comparator in their physical CE even though the phases cannot overlap naturally.

A future source refactor should put residual payload writes in a phase-local physical writer. Its commit enable should use the registered good checked tuple and its current fill owner, with immediate reset/start/cancel/fault masks, without routing a live physical reference-match comparison into every residual word CE. Keep reference failure priority in logical state, owner and publication control. Keep required mode/reset payload zeroing as explicit local events or separately qualify a complete overwrite/copy-mode-zero architecture; do not remove it casually because COPY mode currently depends on zero residuals.

Before this cut, prove the phase invariant `running && !discard_ref && ref_pending -> state==REF_WAIT`, and therefore `state==RESIDUAL -> !response_failure` for a live residual owner. A reference lease is acquired only after final validated residual commit; a good matching ACK retires it before MATH_SEND. Wrong tags retain it while failure revokes the logical frame, and a warm start waits in WAIT_ADMISSION with discard set until the old matching ACK arrives. The physical pending descriptor must never be cleared or rebound by reset, cancel or a new frame.

The V118 response auxiliary provides bounded simulation evidence, not a formal all-trace proof of that invariant. It checks reachable unsolicited offers during real commits: they remain unaccepted and must not block a good residual. It also checks legitimate REF_WAIT wrong tags/matching errors, debt, first fault and retries. There is no reachable simultaneous accepted physical response failure and residual-bank commit to manufacture in a bench. The proposed CE cut is a structural change justified by ownership; it is not a false-path or multicycle constraint.

## Qualification before selecting a V119 source

1. Test all eight nonzero-plane masks and all entropy combinations, with zero planes ignoring entropy as before. Exercise nonce boundaries `0xfffffffc` through `0xffffffff`, needed0–3, other high-bit patterns and random32-bit values against the original64-bit expression. Check entropy64-before-overflow66 priority, no child launch after rejection, and unchanged monotonic child epochs across all three planes.
2. Exhaustively check the small nonce low-bit/count truth table and independently establish the upper-bit reduction identity. For parser extents, test full32-bit addition/wrap endpoints as well as valid mode lengths0–976, truncated payloads, exact/end±1 cursors, nonzero trailing bits, malformed headers and wrong receipt owners. Preserve all existing first-fault codes and no-side-effect early rejection checks.
3. Assert coherent owner preparation, held records, immediate cancellation and reset invalidation. Run the unchanged geometry/cache assertions and the full independent ordered coefficient, residual, canonical, reference-debt and retry suites. Extend prepared peer-fault fixtures only with real task poststates, never fabricated physical leases.
4. Keep the V118 response auxiliary as a control. Add a phase-local writer scoreboard for all64 residual words, unchanged private words, reset/mode zero events, E+2 ordered commitment, invalid tuples and cancel at both stages. Verify every physical reference descriptor field and matching-ACK conservation across reset/start/cancel.
5. Rerun the full18-source component, actual V97 transport and LIVE byte/row publication suites with source-bound proofs. Compare exact successful events/ordered bytes and first-fault/debt semantics; measure any declared cycle changes. Judge the latency milestone using last accepted outer byte→validated parent commit, not whole-fixture elapsed cycles. Broaden the single `actual_001` LIVE fixture before a general gameplay-latency claim.
6. Run one fixed fresh125MHz implementation and100MHz control only after functional qualification. Report setup/hold/pulse, internal endpoint coverage and final routing, inspect all surviving families, and require a separate same-source/method fresh repeat for a positive clock qualification. No timing exceptions, reset fanout attributes or same-source negative reroute search replace the structural work.

These proposals must be coordinated with raw-mode admission and scratch return-state changes; fixing only one family cannot close all independently measured125MHz paths. Sustained hardware30fps and validated under10ms FPGA decoding remain separate open milestones.

The nonce arithmetic candidate now has a source-bound Python prototype and1,036,720 primary matrix cases, documented in `nonce-model.md`. This matures the arithmetic choice for V119 while leaving the critical-branch mapping, RTL integration, temporal ownership and physical timing requirements above open.
