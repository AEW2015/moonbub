The [admission/owner follow-up](admission-owner-next.md) adds source-level hypotheses while explicitly preserving the mapped-chain attribution gaps.

1. **Validate an accepted coefficient on the existing APPEND edge.** Capture the untruncated input tuple, selected full position and immutable expected epoch/phase/range/order context on INGEST. APPEND already writes the packed record and advances `written`/`previous_position`; good coefficients may use that existing edge without a new data-stage delay. Invalid error timing is one edge later and private views can change. Follow the [complete chronology proposal](input-validation-proposal.md): preserve higher-priority reset/cancel/wrong-tag handling, reserve the older coefficient reason against later matching write errors, prevent any new write/assembler publication that an older bad tuple revoked, and drain accepted physical leases. Test every old value/owner/range oracle and an explicit accepted/committed/discarded ledger. Do not preserve old-cycle claims by omitting edges.

2. **Prepare producer/admission bounds and scan decisions under their actual owners.** Break full header/mode/chunk span arithmetic from broad state/CE feedback. Existing header-byte, plane-selection and accepted-receipt edges may register immutable sums, limits and compact decisions before their consumers. Preserve full32-bit fields, wider overflow checks and the exact old invalid-input domain. The plane-block-to-producer path crosses flattened admission/state logic: use a checkpoint fan-in review to identify the exact branch before attributing it to a particular nonce or extent expression. The active-cell scan's large indexed mux/fanout also merits an address-owned registered read with explicit first/last/drain behavior. Added scan latency must be counted; no extra memory port, narrowed bound or silently changed error precedence is assumed.

3. **Give scratch next-address/terminal control a complete local plan.** The output-block path traverses address/terminal arithmetic and then return-state enable logic. Prepare block/bank/epoch, next address, last-block predicate and matching cache-line decision together on an existing fetch/emission boundary. Hold that plan across service stalls. Use the accepted address/epoch for a returned transaction rather than a mutable next cursor. Existing prepared addresses alone do not prove all consumers use a mature plan. Certify every offset, wrap, block transition, prefetch collision, response error and cancel/drain path; declare any new edge. Delay statistics by a separately owned event only if a subsequent actual route identifies them as material, with terminal counter flush and no control feedback.

4. **Localize reconstruction reference validation and residual validity.** A125's pending-FID comparison still reaches residual enables through reference-match/global control. Preserve the complete accepted physical reference lease through reset/cancel until its exact response; never replace it with current-frame metadata. Separate immediate public revocation from private payload retirement. Explore a local validated owner/commit flag and explicit residual-zero/valid semantics so canceled or non-residual modes do not require broad payload clearing on a late global match. COPY mode currently depends on correct zero residuals: removing a clear without replacing that mathematical obligation is incorrect. Prove all64 values, stale-reference/reset/retry, copy/hidden/residual modes, held older heads and every physical response exactly once. Count any new ownership bits, stages or buffers honestly.

5. **Qualify the coordinated source and then measure the integrated system.** Repeat strict focused tests, full independent canonical/transport goldens, peer faults/retry and byte/row LIVE ACK/hash/publication checks for each actual source change. Recompute min/max fixture cycles and measured added edges rather than summing assumed stage costs. At125MHz the current fast-row fixture has104,896 cycles of conditional margin below10ms; the stalled fixture does not fit that budget. Require correct fixed constraints before fresh synthesis, actual nonnegative setup/hold/pulse/internal coverage and routing, followed by an identical-source/tool/recipe fresh positive repeat. Full-parent routing, physical memory/ESP32/display integration and sustained distinct-frame hardware30fps/under10ms measurement are subsequent gates. Passing a component or one synthetic service profile cannot close them.

Prefer one causally justified architecture change at a time for attribution, followed by a coordinated integration source. Preserve unsuccessful evidence and stop unchanged-source negative reroutes. Header arithmetic, accepted tuples, response leases and scan plans need independent ownership proofs; none is safely replaced by timing exceptions or a guessed achievable clock.
