# V121 request timing verification

The initial V121 composition replaces exactly one Source B alias: `fpga/experiments/cu66-v91i2b/byte_refill_queue_v91i2b.sv` resolves to `fpga/experiments/cu66-v121-request/byte_refill_queue_v91i2b.sv`. The other 17 source/include origins, default parameters, top and source order remain those in the V120 handoff. Source B stays byte-identical to `69c0f145d1e3969f5418645a79647634b312214b`. The new register carries the next full unsigned 32-bit request address, initialized on the original start edge and incremented only on an accepted read request. It adds **zero public cycles**. The original offset/issued fields and assertions remain; a new invariant relates the prepared address to their original sum.

The source map is checked independently against the pinned handoff (`1e1bd0f197b8b44e7113f271f2c68092e6800778bbfb3a5027d05f72f9357459`). The focused queue proof must bind the candidate hash before integration launches. No admission bounds preparation, extra elastic stage, physical-memory latency change or parent scheduling change belongs to this first composition. A later composition that adds edges requires its own declared latency model and proof runners while preserving these exact-cycle controls.

## Gates

1. **Focused request ownership and arithmetic.** Compare original and candidate on every edge, including all public values, held request tuples, outputs, statistics, `done`, errors and accepted transfers. Independently track queued bytes, one-edge physical response debt, pending address/epoch/last and consumer order. Prove queued plus pending ownership never exceeds two, credit is reserved on acceptance, and response metadata cannot bind to another request. Cover zero/one/two-byte spans, simultaneous push/pop/issue, full/empty transitions, repeated stalls, stalls at the tail, request-ready refusal, restart, abort/cancel, reset and clear-stat priorities; poison nonaccepted inputs and exercise changing epochs. A request address remains stable whenever a valid request is stalled and no higher-priority revocation occurs.
2. **Full32 and boundary semantics.** Preserve literal unsigned widths: offsets with bit31 set, addresses around `0x7fffffff`/`0x80000000`, `0xfffffffe` length2 and `0xffffffff` length1 are legal queue spans. `0xffffffff` length2 must trip the inherited request-span assertion on the second accepted request in both models. Do not infer that modulo wrap is a legal accepted span merely because addition wraps at32 bits. Preserve `issued<length`, original `req_addr>=offset` assertion, full32 response address and epoch comparison, and exact `last` binding. Admission independently restricts accepted physical replay to `replay_addr<size_bytes`, then indexes its byte RAM with the validated low16 bits.
3. **Cancellation and accepted physical read debt.** A pending queue read is a real synchronous admission RAM access. Logical cancel/start/fault may discard the queue owner, but the already accepted physical read still responds on its original edge; do not mask that response to make a proof pass. Check cancellation before acceptance, on acceptance and at response, outstanding scratch write/read and queued replay ownership, stale/wrong-address/wrong-epoch or unsolicited responses, clean retry without reset and first-fault priority. The producer already gates queue output with kill conditions and the admission already gates acceptance with reset/start/abort; both paths remain unchanged.
4. **Complete decoder and actual transport.** Reuse the frozen V117 command-API and transport harnesses, V113 independent canonical goldens, and all original functional/held/error/counter/drain checks. Run seeds107601/107602:22 case profiles and21 directed checks each, plus actual V97 transport with12 successful profiles, two abort/reset retries and16 accepted/delivered/poisoned command tuples per seed. Require byte-exact stdout and accepted-event files, including every cycle, against qualified V120 Source B; require canonical TSV raw hashes exactly equal to independent V113 fixtures. Six goldens/profiles repeated through48 records do not establish48 distinct gameplay frames.
5. **Peer and physical debt.** Reuse the unmodified V118 prepared-fault peer bench and original injection contract, seeds115501/115502. Per seed retain eight directed checks/eight child canonical retries,14 prepared child fault injections, accepted-write2/accepted-read4/queued-replay2 cases, six real-parent abort/reset cases covering all three scratch boundaries, and14 total canonical retries. Compare every stdout record and raw accepted-event/canonical artifact exactly against Source B, retaining every original assertion and `need`.
6. **Guarded complete parent.** Reuse the frozen V117 live guard and V116 byte/row endpoints, with byte and row variants, seeds116701/116702 and both finite-service profiles. Retain C2 root, canonical bytes, HUD SHA, seal, all1025 hash jobs, ACK/request byte accounting, physical-owner draining, wrong-token ACK and retry checks. Require all six terminal dictionaries and all raw events/actual/hash artifact hashes, including their cycles, to equal Source B. The existing fast/stalled row fences therefore remain1,145,104/1,553,197 last-input-to-commit cycles if this gate passes; V121's declared delta is zero.
7. **Composition binding before native.** `integration/collect_final.py` rehashes all source and retained artifact pins, requires focused/full/peer/both-parent PASS receipts and strict compile flags, then writes `experiments/python-gamebub-v121/integration/results.json`. Native preparation must consume that source map and receipts, retain the fixed clock/part/tool/recipe, and measure actual routed request arithmetic/readiness paths. A moved worst path or reduced carry count is diagnostic evidence; positive component timing requires all setup/hold/pulse/coverage/routing gates plus a separate fresh same-source repeat. Complete-board routing, physical service, sustained30fps and hardware validated decode below10ms remain separate.
