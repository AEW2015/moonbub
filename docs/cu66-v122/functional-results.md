# V122 functional results

The new admission bounds pipeline passes the four-stage regression and the
independent raw-stream audit. Public values, events and cycle counts match the
frozen V121 composition. V121 already establishes exact Source B equivalence;
this iteration executes the new candidate and compares directly with V121.
The original Source B binaries are comparison evidence, not newly rerun models.

The [unified source-bound index](../../experiments/python-gamebub-v122/integration/results.json)
selects the focused, complete-component/transport, peer and byte/row parent
receipts. The [independent audit](../../experiments/python-gamebub-v122/audit/full-independent.json)
rehashes their sources and artifacts and independently compares ten sets of
raw stdout, event, canonical and parent hash streams. It retains all eighteen
source/include origins; only the admission alias changes from V121. The V121
prepared request queue is unchanged.

The random prepared-domain cases drive coherent predecessor phases through real
RTL edges. They are distinct from natural packets, and their priming clocks
are excluded from natural-packet latency claims. No new predicate is forced to
manufacture a match. Original RTL assertions remain active, and every Verilator
compile retains `--assert -Wall` without warning downgrades. Executable builds
and the separately compiled V97 adapter retain strict host compiler flags.

Per seed, the inherited checks include 25,344 chunk boundaries, 294 boundary
cancellations and 67,664 full-width header cases. The added random cases include
6,772/6,657 full64 high-word cases and 3,277 uint32-wrap cases in each seed.
These finite tests exercise the general arithmetic contract; they are not a
formal proof over every possible packet.

## Preserved latency and output

The measured public-cycle delta is **zero** throughout the retained comparison.
The four parent post-input-to-validated-commit counts remain:

| Abstract service variant | Profile 0 | Profile 1 |
| --- | ---: | ---: |
| Byte | 3,704,705 cycles | 9,484,147 cycles |
| Eight-byte row requests | 1,145,104 cycles | 1,553,197 cycles |

All profiles retain the same C2 root, HUD SHA and seal. They repeat six golden
fixtures/profiles. They do not establish sustained distinct gameplay, actual
ESP32/RF throughput, physical SDRAM service or board presentation rate.
The new pipeline changes timing structure while preserving these cycle counts.
