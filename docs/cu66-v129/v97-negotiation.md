# V129 V97 host-to-portable-receiver evidence review

The [V97 exchange](../../experiments/python-gamebub-v129/v97-negotiation/results.json) **passed as a native, local protocol test**. It runs the repository's Python host session against the portable Rust `Receiver` through a line-oriented subprocess bridge. It does not run the deployed streaming path.

The [receipt](../../experiments/python-gamebub-v129/v97-negotiation/attempts/20261111T002517433617Z/receipt.json) records a network-disabled Docker command, successful exit, Rust 1.99.1 compilation with `-D warnings`, and execution of the Python exchange and compiled bridge from a read-only source snapshot. The selector's receipt hash, all six frozen source snapshots, and all ten recorded artifact hashes were independently verified. The [freeze](../../experiments/python-gamebub-v129/v97-negotiation/attempts/20261111T002517433617Z/freeze.json) records that the two protocol source files and host package initializer matched the recorded Git HEAD at test time. This review did not rerun the test.

The [exchange script](../../scripts/cu66-v129/v97-negotiation/exchange.py) exercises setup and ACK acceptance; rejects a send before ACK and a one-bit mutation in each of the 40 ACK bytes; sends a 2,801-byte **synthetic payload** in three fragments; checks fragment index, offset, count and final CRC completion; and checks idempotent setup, replay rejection, wrong core generation, and same-epoch parameter change. It checks that each of four research profiles is rejected by the default receiver and accepted by a separately configured matching host and receiver. The [stdout verdict](../../experiments/python-gamebub-v129/v97-negotiation/attempts/20261111T002517433617Z/stdout.log) is consistent with these assertions. The bridge returns chunk metadata and completion state, not reconstructed payload bytes; this test does not decode or visually assess JPEG.

The actual host and receiver are the portable [Python V97 protocol](../../host/moonshine/protocol97.py) and [Rust V97 receiver](../../firmware/handheld/src/streaming/protocol97.rs), not a running Sunshine capture/encoder, active MSV1 network worker, ESP32 firmware, Wi-Fi stack, QSPI transport, FPGA or display. Research-profile acceptance only establishes the tested negotiation and opaque six-byte fragment path; it is not proof of codec support or hardware compatibility. No packet loss/reordering campaign, long-duration run, throughput, 30 fps, end-to-end latency, under-10-ms FPGA decoding or hardware result is established here. The Rust `Gateway` staging and physical acknowledgement behavior are not exercised by this bridge.
