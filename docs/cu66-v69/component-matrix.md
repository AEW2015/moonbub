## Interpretation

The component rows provide testable contracts and reusable evidence for root integration. In particular, local PASS results do not by themselves prove correct late-error rollback across all modules, atomic global frame publication, synchronized reset/drain across physical buses, or actual display output. The portrait proof confirms address mapping against the checked-in scanout RTL, but its alternative layouts are locality models rather than fitted memory architectures. None of the behavioral cycle counts should be divided into a clock-rate or reported as measured frame rate.

The [independent component audit](component-audit.json) reconciles ten frozen scopes: 70,433 checks, 11,730 declared-hash comparisons, no stale/mismatched records. One provenance warning remains: original IDCT evidence did not bind historical log hashes; its current transcripts are observed, not retrospectively certified. Connected integration and the software HUD gate have their separate checks.
