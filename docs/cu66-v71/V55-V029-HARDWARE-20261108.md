# V55/V029 custom-codec hardware check

The subsequent no-pause forty-frame tests are recorded in [the V57 hardware result and next memory plan](V57-CLIP40-HARDWARE-AND-NEXT-20261108.md). The slow successful test below is historical; longer playback remains incomplete.

The November 8 local hardware test passed **12 accepted / 12 presented / 0 rejected / 0 underruns**, with matching DYN1 status-2 replies for every frame. The receiver verified all **253,440 HUD words**. The camera shows the decoded game scene. First-to-last presentation spanned **28.188 seconds**; receiver elapsed time was **29.283420 seconds**.

This was an intentionally slow twelve-frame test, with a two-second pause after each presentation. It is **not twenty seconds of source footage or a sustained FPS result**. Continuous video remains the next qualification step.

- ESP32: V55, SDK ELF `ef005e82d795b3ea1bdb6248901b821a7b5e78ad753de5fe0b6d2766a663976b`.
- FPGA: V029, BIT SHA-256 `59a2439488c529941661debcf3f3c75f8fd2f6e61418c3c63a45e377e971e7c3`; JTAG verified DONE=1, USERCODE=`44593741`.
- Routed setup **0.000 ns**, hold **+0.008 ns**, pulse **+2.000 ns**. The user explicitly accepted zero setup margin for this lab test. Constraints stayed unchanged, all nets routed, and bitstream generation reported zero DRC errors. Two inherited CDC findings remain documented.
- Host: `192.168.0.33:57896` to `192.168.0.157:5535`, session `277621397986464872`, original packaged frames 0–11.
- Two independent exports passed all 43 checksum/index records, with the same `6ab5bf98` checksum. The diagnostic ring retains details for the last three frames; earlier per-frame timing records are omitted.
- Worker stack low-water reading: 2,776; minimum internal-free reading during native work: 17,952 bytes. These observations are not a whole-stack proof.

The app-only update first hit the host's ten-second ERASE deadline. Read-only status proved that the original erase completed. Recovery verified the erased span and untouched regions, wrote V55 exactly once without another erase, and verified the entire factory slot plus updater/table preservation. One normal software reboot returned working CDC and the exact V55 identity. The original failure journal and private raw backups remain preserved; no automatic retry occurred.

The sender is stopped. The receiver deliberately retains its endpoint/lease and final image. Do not reprogram underneath that ownership; use the reviewed explicit recovery controls before another test.
