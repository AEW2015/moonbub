# Selected CPL1 local evidence

Physical snapshots are parsed from USB observations; their parser status alone does not attest hardware origin. Selected runtime and FPGA identity logs bind this report to the controlled local window. Full private logs and camera footage remain local. SHA256.json binds the selected files.

Analysis scripts are the executed provenance copies, with the original workspace-relative evidence paths. They are not portable release runners. The model sensitivity cases are simulations, not board delay measurements.
