# Python Game v17 evidence audit

Read-only audit for the v17 paced gateway, streaming memory, and local refresh studies. The target is 720×480 coded, 720×405 active at 30 fps. The paced gateway and local refresh inputs have final signals and are verified. Streaming memory remains pending until its explicit final signal and strict-boundary review; the overall audit therefore remains pending.

The local refresh replay checks six cases and 848 captures against 37 source pins, the 25-test log, and a bound untimed analyzer. Its global-control comparison retained 159 strict / 161 eventual presentations and 133 unique decoded IDs per five-second diagnostic window; local refresh retained 176 / 178 and 151. The 30.2 IDs/s rolling count is phase/catch-up under a 30 IDs/s schedule, not capture rate or continuous 30 fps. Local maximum presentation gap remains 66.667 ms. Exact UI coverage is 21,120 RGB565 words per native decoded frame. AR03/AF03 v3 is experimental; current firmware remains MSV1 JPEG-only.

The prospective paced gateway replay checks 36 scenarios, 14 source pins, and 11 passing study tests. It verifies six data credits plus one reserved control token, zero modeled mailbox overflow, and the bounded feedback-blackhole stop with six outstanding credits. Nominal paced opaque-body completion is 175 strict / 176 eventual from 177 ready bodies; these size traces are not decoder-valid reference histories. Maximum-body stress admits/completes 35 of 60 and needs 12.78432 Mb/s at 30 Hz before reverse feedback. Neither model establishes ESP32 CPU/RF/FPGA hardware performance or physical 30 fps; dropped frames are not counted as a throughput gain.

The streaming-memory replay checks eight main scenarios, four short phase cases, 28 source pins, 12 passing tests, and the hash-bound epoch-boundary analysis. Fast streaming reports 29 logical epoch starts and 29 clean epoch finishes strictly before the one-second endpoint, with 30 eventual clean epochs after drain; its interior half-second window has 15 model IDs. Four scanline FIFO lines with the 200 µs stall miss 3,689 line deadlines and produce no clean epoch, while eight lines pass in that conditional model. The workload repeats byte/work templates from three native coefficient traces; it is not a valid AR02 reference-history replay or 30 distinct gameplay images. The 2 MiB address window is rejected. None of these scenarios qualifies fitted memory, FPGA timing, a physical panel, or 30 fps.

Source pins are rendered as portable paths relative to the repository. Pins containing the original `/moonbub-30fps-study/` suffix are remapped to the current repository root.
