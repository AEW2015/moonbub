# `gamebub-display-compose-v21`

`source_sha256` pins executable sources, old fixture objects/results and the
HC21 campaign. `vectors` lists ten isolated CB21 fixtures, each identifying its
v20 scene and vector index. Each stored zlib object has a safe relative path,
stored/raw SHA256 and exact raw length. Load the v20 fixture's specified YUV
banks before decoding; the ten vectors are not a self-contained video stream.
HC21 cache decisions within each five-vector sequence do form a separate exact
ACKed display-cache sequence.

`budgets` has two 48-row native source cases. Every row retains original and
proposed complete bytes, the strict 49,152-byte cap outcome, component sizes,
full directional IPv4/UDP counts and 25 assumed network-only rate/delay bounds.
Summaries retain totals, complete-byte savings and 30-ID/s directional projections.
They include CB21's 57 bytes and HA21's new reverse bytes.

`exact_display_words` counts full-canvas comparisons, not only HUD words.
`exact_yuv_samples` counts unchanged decoded samples. Neither count is FPS.
`limits` states integration, timing, physical and publication gaps explicitly.
