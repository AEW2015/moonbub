# Display-filter quality gates across native points (V63)

V63 evaluates the frozen V60 identity and stronger display presets on all 69 archived native points: 48 coarse V61 points plus 21 targeted peak-rate controls. It re-decodes 1,656 native presentations and compares 3,312 filtered display variants. Encoded bytes are unchanged; this is a quality/frontier analysis, not another native encode campaign. Sixteen custom policy/cohort comparisons use the same fixed filter options.

The independent verifier rederives every filter and quality sample and recomputes post-filter mean/peak gates. Cap failures remain represented. The selected gate is not an optimal native frontier, subjective-quality judgment, standards-decoder proof, hardware-fit result, or FPS measurement.

Reproduce with `compare.py` and `verify.py`. Three gate tests and the independent replay pass.
