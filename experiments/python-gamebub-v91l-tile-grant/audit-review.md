# Policy audit scope

The new grant observer forwards every event unchanged to the frozen overlap
checker. Candidate/canonical/reference/RGB bytes, all SHA jobs, scratch child
epochs, one physical controller's pin command/data/timing, protected bank and
actual publication/consumer-lease checks are preserved. Old memory contents
are learned only from real pin WRITE commands; no logical or golden preload
populates the oracle. The C++ bench is exactly the old workload after top-type
renaming, preserving its PRNG and input/output scheduling code.

The policy replay checks complete response ACKs, one pending line, contiguous
same-tile epoch/bank/ticket scope, skip-zero rollover, credit count, all eight
idle-gap observations before timeout, and a fresh round-robin opportunity
when a group releases. Eligible display-offer start/end timestamps reconstruct
request-wait maxima. Native runs require no canceled waits and complete
coverage of all 64,800 display requests. The frozen baseline did not record
this exact wait instrument; no baseline maximum is inferred.

The unit's legacy/candidate REF_LINES1 instances emit two identical copies of
ordinary mux receipts. Those pairs must match exactly before deduplication;
cycle-by-cycle assertions separately compare every ordinary output, including
ready when valid is low. Each source-reviewed cold-owner-idle boundary starts
a new independently closed scenario and resets telemetry history. The unit's
physical responder is abstract. Actual controller/timed pins are covered by
the native campaign.

The raw yield event omits some unaccepted cancel/mismatch inputs. Those
specific cause checks rely partly on the reviewed directed bench; the replay
independently checks ownership/credit/ticket/address/gap/data-path invariants
and native runs require only full successful four-line group yields. No
exhaustive formal or arbitrary-backpressure wall-clock bound is claimed.

Batching also changes effective read-credit weighting, not only row locality.
Report the key-display slowdown alongside any pair/decode improvement, and
qualify a separately balanced policy before product promotion.
