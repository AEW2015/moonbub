# Rice-rate search experiment

The qualified baseline files remain unchanged. This directory adds a host-only parameter search for the existing EC94 N2S10 profile. It evaluates all legal Rice parameters independently for each DC, AC-run and AC-level model: 14, 20 and 12 parameters respectively. Each candidate builds its category histogram and uses the frozen normalizer. Its score is literal bits plus `sum(count[q] * log2(1024 / frequency[q]))`. The lowest score wins, with the lower parameter winning an exact score tie.

The score approximates encoded rate: it omits exact lane terminal effects, byte rounding and coupling between alternating fields. It does not promise a globally optimal bitstream. Both the chosen-parameter stream and the frozen BR-parameter N2S10 anchor are actually encoded. The shorter actual context stream is retained; an equal byte length retains the frozen anchor. All inline tables, descriptors, lane states, literal and ANS bytes, packet headers and CRCs are charged.

Three actual packets are collected per plane: the frozen N2S10 anchor, rate search guarded by that actual byte anchor, and local minimum of frozen AB, frozen BR and guarded rate search. The `method_stream_bytes` and reported `methods` use indices 0=AB, 1=BR, 2=frozen N2S10, 3=guarded rate search. Packet wire methods remain the qualified EC94 values: 0=AB, 1=BR, 2=two-lane rANS.

Generation time includes source decode, AB and BR generation, AB internal validation, explicit BR decode validation, anchor and proposed rANS stream generation, every discarded k histogram/normalization/score, byte guard selection, three assemblies and three hashes. `search_ns` is a subtotal of `prepare_ns`; it must not be added again to `generation_ns`. Native all-three decoder validation is timed separately. The independent Python decoder validates all three actual packets, and the anchor bytes must exactly match the qualified original N2S10 packet for the same frozen chunk.

The unit test covers six coefficient families, the exact frozen anchor, no-regression bounds, every explicit legal parameter pair with escapes, empty-model lower-k ties, and native coefficient parity. The finite full campaign records source pins and snapshots, strict container compilation, all-three independent validation, actual bytes, retained attempt logs, and measured native/Python peak RSS. This experiment adds no trained-model, cache, tANS, physical timing or frame-publication claim.
