# V100 standard-frontend paired simulation adapter

`cs88_pipeline_v91k.sv` is a verification-only adapter generated by
`scripts/cu66-v100/run_converted_rtl.py`. It keeps the exact original public
port declarations and passes every port once by name to the converted top.
The converted top is renamed once to `cs88_pipeline_v91k_sv2v` in the retained
attempt copy. The wrapper contains only wires, direct named connections and
slice assignments; it does not add clocking, state, reset or control logic.

The standard sv2v converter packs an unpacked `[0:N-1]` output so element zero
occupies the high slice. The nine original output arrays are restored as
`original[i] = converted[(N-1-i)*element_width +: element_width]`.
`port-mapping.json` lists their exact dimensions. The independent
`experiments/python-gamebub-v100/converted-rtl/port-audit.json` checks all 308
ordered port names, directions and total widths against the generated source.

This is source conversion plus bounded simulation qualification, not formal
equivalence or mapped-netlist verification. The conversion uses official
sv2v 0.0.13 with `-D SYNTHESIS --exclude=Always`; `always_comb` and `always_ff`
remain intact, and the physical synthesis branch naturally omits RTL
assertions guarded by `ifndef SYNTHESIS`. Original-side RTL assertions and
all unchanged C++ checks run with `--assert`; no checker source is edited.

The unchanged full V91k pipeline bench uses its historical 11-fixture corpus,
including FAST/SLOW memory profiles and 21 cancellation, reset, admission and
reference-service checks. Each of seeds 911501 and 911502 runs both original
and converted full component variants. Acceptance requires explicit terminal
`TEST_PASS` from every run and byte-identical same-seed full transcripts,
cycle counters, per-stage events and actual canonical SRAM bytes. Those exact
canonical bytes are also replayed through the unchanged RGB565 secondary
RTL/bench, with 12 case/profile runs and eight directed checks per seed.
The RGB block is separate from the converted physical component.

The historical corpus here qualifies the full standard-converted V91k
component. Fresh V99 q16 source qualification is the separate unchanged V91j
run documented in `docs/cu66-v100/rtl-results.md`.

The first strict converted compile stopped on 245 generated-code warnings.
The retry retains every warning with the documented Verilator `-Wno-fatal`
option, and rejects any class outside the seven observed categories:
WIDTHEXPAND, WIDTHTRUNC, UNUSEDSIGNAL, EOFNEWLINE, DECLFILENAME, ASCRANGE and
UNUSEDPARAM. Original RTL and C++ compilation stay strict. Width-cast behavior
is accepted only through the explicit original/converted output and cycle
comparison. No warning is hidden and no assertion severity is reduced.
See the [official Verilator option documentation](https://verilator.org/guide/latest/exe_verilator.html#cmdoption-Wno-fatal).

Results and immutable attempts are under
`experiments/python-gamebub-v100/converted-rtl/`. The physical mapper must
consume a final `verification.json` receipt with `PAIRED_RTL_PASS` and the
exact converted source hash before interpreting any mapped leaf result.
