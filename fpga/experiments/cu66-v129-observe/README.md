# Opt-in simulation-only latency monitor

`prepare.py` derives `tb_keyframe.cpp` from the SHA-pinned V117 live-guard bench; it never modifies the selected RTL or the original bench. `prepare_runner.py` derives a separate runner from the strict V129 live-parent runner. The run requires `--run --root-grant ROOT_V129_MONITOR --variant row`. It is not part of normal firmware, RTL synthesis, or a hardware interface.

At each included pre-edge sample the monitor records seven ready/valid pairs as no-valid, held-valid, or accepted: coefficient producer, staged inverse input, residual, canonical output, write/hash join output, physical request and physical response. The physical outstanding flag is the bench's finite-service `candidate_pending`, not an independently observed SDRAM controller. Per-channel bins partition sampled cycles; a channel without valid may still have work upstream, and a stalled channel does not prove root cause.

The 128-entry mask preserves simultaneous held-valid observations for the first six channels plus pending ACK. Physical-response held-valid is in its handshake bins, not the mask. `priority_counts` assigns each cycle to its lowest numbered set mask bit, or the final no-observation bin; this is a reproducible mutually exclusive classification, **not** causal or additive speedup attribution. Samples start at the accepted parent start and stop once `commit_cycle` is observed; the bench's kill predicate excludes reset, abort, validator/join error and metadata-mismatch edges. Other bench phases and accounting have different boundaries. Reset/error behavior, full physical service, and back-to-back frame throughput need separate experiments.

`check_unit.py` compiles a strict standalone test that exercises simultaneous blocked signals, transfers, response stalls and accounting conservation. This unit test does not compile the generated parent or establish an FPGA timing or throughput result. A successful separate full-parent receipt is required for actual signal binding and full functional checks.
