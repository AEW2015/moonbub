cu70_system.sv header is the frozen functional interface. cu70_system_sim will expose the same functional signals but replace SDRAM pin ports with read-only verification peek and command counters/events. Packet request identity includes generation64/sequence32/address16; responses echo all three. HUD auxiliary requests also include generation/frame ID and are allowed only for the currently prepared candidate HUD region. Hardware/receiver semantics are unchanged; pixel outputs are actual native LCD line RTL, so modeled memory service may produce underruns.

`USE_STRIP=0` selects the baseline painter; nonzero selects `cu70_painter_strip` through the identical scalar memory API. Both hardware and simulation tops expose the parameter, and both are in sources.json. Qualified control logs before this parameter were preserved as control-pre-strip.*.
