# STB1 inference verification result

The exact FIFO RTL synthesized out of context passed the final black-box functional-netlist suite using official Xilinx primitive models. The selected full routed design also has the expected RAM address/data configuration. This is an OOC behavior gate plus selected routed structural audit; it is not an exact behavioral replay of the optimized full routed cell.

Final combined receipt: `result.json`. Final common testbench: `tb_stb1_blackbox.sv`. Final RTL control is `rtl04`; final OOC netlist replay is `ooc-netlist09`. Both use the same source hash, preserve strict unknown-state assertions, and pass all 10 cases: eight complete 256-entry fills, multiple wraps, all three partial tails, stale high generation, queue reset/reuse, in-window overflow/drain and scalar collision/passthrough. Every valid accepted word is checked against an independent pattern and CRC. The actual selected native staging source, parameterized to 8,192 bytes for the bounded test, returned 13,329 matching bytes through its real packet read port. No DUT internals are referenced by the qualification harness. The OOC simulation took 32.5 seconds.

One authorized Vivado invocation opened the immutable selected routed checkpoint, emitted primitive properties and connectivity, closed it, and synthesized the exact FIFO source separately with hierarchy preserved and a test-only 10 ns clock. It exited successfully. Neither the selected DCP nor FIFO RTL hash changed. Its artifacts are in `C:/moon/builds/stb1-inference-ooc-v001`:

- `selected-primitive-map.tsv` and `selected-fifo-properties.rpt`: actual full routed cell queries.
- `ooc-primitive-map.tsv`, `burst-ooc-funcsim.v` and `burst-ooc.dcp`: separate OOC synthesis.
- `mapping-comparison.json`: explicit configuration and address-role checks.
- `inputs.json`, `command.json`, `execution.json`, logs and Tcl: reproducible input/command receipts.

Both physical primitive mappings are RAMB18E1 SDP, read port A width 36/write width 0 and write port B width 36/read width 0, with no optional output register and READ_FIRST modes. In both designs, read address bits 12:5 derive from rp registers0–7; write address bits 12:5 derive from wp registers0–7. Selected routed low 16 data bits enter DIADI from the numeric payload word and high 16 enter DIBDI; DOADO/DOBDO feed the corresponding fifo_q halves, with count metadata on parity paths. The TSVs include actual data/control nets and fanin/fanout endpoints. The historical write-pointer/read-pointer swap is not present in this selected RAM structure. Cross-boundary logic optimization changed the routed cell's interface to generated control/data ports; no mapping back to original RTL ports was guessed.

Initial OOC simulations failed because fault became X immediately after reset release. Those failures are retained in `ooc-netlist01` through `ooc-netlist07`, including executable VVP artifacts and logs; `retained-failure-bindings.json` hashes them. Exact source text evolved during diagnosis, so those failed variants are replayable via their saved compiled artifacts, not all reconstructable from the final testbench alone. Internal primitive probes were isolated in `primitive_startup_diag.sv` and `startup-diag*`; they are not part of the qualification harness.

`lut6-startup-repro01` contains a tiny official-model reproducer: LUT6 INIT FFFFFFFEFFFFFFFF, known I5=0 and otherwise irrelevant unknown inputs initially returns stale X, although the selected lower cofactor is all ones. An unrelated input transition then produces 1 as required. The installed primitive uses initialized INIT_REG but its procedural sensitivity list contains only inputs. Static time-zero testbench input initialization can therefore race primitive initialization. The final common harness applies all external input values at 1 ns, allows the 100 ns global GSR startup to finish, and starts the bounded reset after 200 ns. It does not initialize or force DUT state, alter the netlist/RTL, mask unknowns or relax assertions. Reset, descriptor, drain and expected-fault checks were strengthened to case inequalities. The unchanged RTL also passes this exact final stimulus.

The library emits ordinary warnings selecting typ RAMB18 expressions. No SDF was applied. This result does not prove routed full-cell behavioral equivalence across its optimized boundary, board timing, clocks, SDK/QSPI throughput, arbitrary oversized raw-burst containment or hardware playback. The separate 1,024-byte raw driver limit still applies; the in-window overflow case does not replace the retained 257th auto-increment word limitation diagnostic. No further Vivado or hardware operation was performed.
