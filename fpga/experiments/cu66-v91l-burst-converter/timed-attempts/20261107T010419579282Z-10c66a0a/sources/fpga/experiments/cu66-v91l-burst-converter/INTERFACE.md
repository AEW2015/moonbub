# Owned-line direct-byte consumer experiment

`generate_converter.py` mechanically derives the candidate from the frozen V91k/V91l sources and records both hashes in `derivations.json`. The scalar build compiles those frozen sources with only an observer top; the burst build compiles the generated derivatives. Both use exactly the same retention reader, BL8 bridge, writepipe SDRAM controller, timed pin model and C++ stimulus. The top variants live in separate directories to preserve matching Verilog module filenames under strict `-Wall`.

The core offers `probe_valid`, `probe_addr[18:0]`, `probe_epoch[31:0]` independently of external request validity. The line adapter returns `probe_hit` and `probe_data[7:0]` from its existing three 16B plane slots. Only eligible FILL_REQ/LUMA_REQ edges consume hits. A chroma hit drives the same single-byte-enable RAM write structure as a successful byte response; publishing row validity follows committing its final byte. Luma hits enter the unchanged registered lookup/conversion path. Misses retain the frozen byte lease, canonical16B gather and physical memory path. Probe validity is blocked by inactive/incorrect epoch, pending physical/byte ownership, held byte response, start/finish/reset/cancel/error and incorrect address/tag. Existing bank/generation ownership remains in the unchanged outer lease and reader.

There are **zero additional payload bytes, line owners or frame owners**. The new probe is combinational. The only added sequential state is two64b diagnostic counters. Existing line payload is48B; existing chroma-row RAM payload remains1440B. This experiment does not establish a physical combinational-path timing result.

`count_reads` and `count_responses` remain actual external core byte leases and returns. `count_direct_consumes` counts successful direct hits, and `count_canonical_consumed` counts successful external responses plus hits. Expected full-frame burst values are32400/32400/486000/518400 respectively. Scalar observers report direct0 and consumed=`count_responses`; original scalar counters and modules are unchanged. Adapter `count_hits` still means externally leased adapter hits: scalar486000, burst0. It is not repurposed to include direct probes.

The event stream adds accepted `byte_req`, consumed `byte_rsp` and `direct_byte` receipts with cycle, address, epoch and data/error where applicable. Frame records expose the four counts, adapter hits/misses, original state histograms and physical ownership occupancy. The seven frozen directed/unit+native checks remain named identically. Stimulus uses the same seeded20% output-ready deassertion rule in each static build; differing cycle counts imply differing positions in the same pseudorandom sequence.

Run `python3 scripts/cu66-v91l-burst-converter/run_comparison.py` for both seeds912701/912702 and both tAC2/7ns corners. Attempts retain snapshots, failure logs, compiler commands, native RGB outputs and compressed receipts; the alias `timed-results.json` selects the latest attempt. Assertions and warnings are enabled, C++ uses20 and `-Wall -Wextra -Werror`, and watchdogs are finite. A preloaded canonical source and functional timed SDRAM model do not prove live codec latency, FPGA timing closure, continuous hardware30fps or full-frame under10ms decoding.
