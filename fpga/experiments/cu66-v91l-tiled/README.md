# Static raster versus tile8x8 candidate placement

This gate changes logical-byte-to-physical-address translation in the bounded four-credit candidate row bridge. Both variants use the **same frozen pipelined SDRAM controller and pin model** from `cu66-v91l-writepipe`. Raster control also uses that frozen bridge. New `row_to_sdram.sv` is generated by `generate_bridge.py`; its receipt records the exact helper/mapping/alignment-assert replacements. No frozen source is modified.

The canonical planes are Y 720x480 at byte 0, Cb 360x240 at 345600, and Cr 360x240 at 432000. For a plane-local coordinate `(x,y)` and plane width `w`:

```text
physical_byte = base + ((y/8)*(w/8) + x/8)*64 + (y%8)*8 + x%8
physical_word = (candidate_bank << 22) | (physical_byte >> 1)
```

All divisions in synthesizable mapping use literal 720 or 360, and literal 90/45 tile-row multipliers. There is no runtime selectable-width divider. The result still needs synthesis and routed timing/resource analysis; source arithmetic does not establish low-area hardware or a met timing path.

HUD bytes 518400..560639 remain linear. Dimensions are divisible by eight, so tile8x8 adds no padding or larger frame buffer. An accepted aligned eight-byte row maps to four contiguous physical words within one row. Response addresses remain logical, preserving the existing epoch/token/bank/address completion contract.

Request validity remains epoch nonzero, provisional bank0..2, eight-byte alignment and final start address <=560632. A bridge cannot infer accepted/reference/front roles. The caller must grant a provisional-bank lease and prevent reuse until drain; this standalone gate does not add role authorization or atomic frame publication. Warm cancel/reset stops new word acceptance, retains the exact accepted prefix, and waits for final idle before its cancellation response. Already modified words are not rolled back. A previously offered held response remains immutable under later warm kills.

The shared testbench retains the prior 25 unit checks and adds plane/tile/chroma/HUD boundary checks and an actual BL8 readback of two physically adjacent mapped tile rows. Raw controller probes remain physical addresses. The source-backed native fixture preserves its 140160 original logical requests, byte payloads, banks, epochs and tokens. The runner gathers every actual native physical WRITE, independently inverses the map, checks full canonical+HUD bank SHA-256 goldens, and records ACT/PRE/REF counts and first-accepted-row to final-drained-response cycle windows.

```sh
python3 scripts/cu66-v91l-tiled/run_comparison.py
```

Default campaign: two static variants, two seeds, tAC2/7-ns unit corners; full key+delta native replay additionally runs at2ns for both variants/seeds. `--unit-only` does not qualify native replay. Main builds use strict Verilator5.020 timing/assertions/warnings and GCC13 C++20 warnings, with two compile jobs and finite watchdogs. Sources, inputs, commands, failures, versions and raw compressed receipts are retained per attempt. The SV packed-string ternary pads the raster config label to `" raster"`; readers normalize that formatting with `strip()`, without changing any address/data receipt.

Each native frame writes70,080eight-byte rows with280,320word commands and560,640bytes. The bridge still serializes logical owners through final recovery and response consumption. Tiled placement does not remove that per-row scheduling cost, live decoder work or other memory clients. A write-only fence below10ms does **not** establish complete validated decoding below10ms.

The timing fence is **write-only replay** of previously decoded bytes, not live codec reconstruction/HUD/hash/publication, shared scratch/reference/conversion/scanout service, or hardware latency/FPS. The selected model is functional with finite command timing checks; it is not a vendor/PVT model, SDF, I/O timing closure, physical FPGA fit or board test. The separate row-retention RTL work is not silently included in this gate.
