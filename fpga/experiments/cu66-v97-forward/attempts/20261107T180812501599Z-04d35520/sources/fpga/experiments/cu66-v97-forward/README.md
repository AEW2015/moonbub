# V97 standalone bounded DMA/FIFO ingress

This synthesizable RTL is an experiment at a **synchronous parallel command and byte-DMA boundary**. It is not wired into `moonshine_qspi_endpoint.sv`, and the test does not serialize QSPI pins, run ESP32 instructions or exercise a physical SPI/DMA driver. The retained production register `0xe000000c` reports remaining frame bytes; it is not this experiment's FIFO credit contract. Neither legacy cores nor the JPEG decoder gain this capability from these files.

The explicit capability is `0x56393743` (`V97C`), version 1, capacity 2048 logical bytes, maximum DMA length 1400, alignment 4, two descriptors. These outputs describe the standalone module; a future real register adapter must export and validate them before using this contract. Generation zero is unconfigured. A negotiated nonzero generation must be installed with `core_change`; a reset requires a fresh negotiated session epoch before any new traffic. Core generations and epochs must not be reused across their lifetime; full identifier wrap requires a fresh drain/reset negotiation.

`START` binds generation, nonzero epoch, frame ID, length 1..262144 and expected IEEE CRC32. The caller additionally enforces its negotiated profile cap, including 49152 for the opaque research profiles. A reservation atomically checks generation/epoch, actual free capacity, 1..1400 logical length, remaining frame length, and a free descriptor. It receives a monotonically increasing token; token exhaustion rejects until generation changes. Abort flushes the FIFO/descriptors and preserves token progression. Core replacement flushes and installs a different nonzero generation before resetting tokens. A repeated generation flushes without resetting tokens. No expected drain grants credits.

`free_bytes = 2048 - fifo_used - reserved_bytes`. Each reservation occupies a descriptor until its ACK is accepted. Each accepted logical byte moves one reserved byte to the FIFO and updates CRC; only an actual sink handshake releases FIFO credit. Reservations plus occupancy cannot exceed 2048. The two descriptor slots can remain occupied while ACK is held, even after the sink has drained. ACK generation/epoch/token identify the completed DMA. Consumers must match that tuple before treating the output ACK as a software completion. The ACK handshake is ready/valid; it is not an incoming independently addressed ACK command.

DMA bytes must match the generation/epoch/token of the oldest not-yet-complete descriptor. The source must send exactly its reserved logical length. Aligned backing-buffer tail padding is not sent to this byte interface. A future QSPI adapter must preserve that distinction. Rejected command/data attempts have no allocation/data effect and pulse `reject_pulse`. As a synchronous ready/valid interface, waiting sources should check ready before asserting a valid command; a held valid not yet ready can pulse rejection without consuming it.

The sink receives generation/epoch/frame ID with every byte. Its bytes remain a tentative transaction. Abort/core replacement pulse `cancel_pulse`; the consumer must discard tentative state on cancellation/reset. `commit_pulse` requires exact received and drained counts, zero FIFO occupancy, all DMA ACKs retired, matching identity and CRC32. It means **ingress complete only**. Decoder syntax, JPEG marker checks, accepted reference, C2/HUD seal, memory visibility and display publication remain outside this module. A CRC mismatch latches an error until cancellation; missing bytes or held ACK never produce commit.

Run `python3 scripts/cu66-v97/run_forward.py --trace <native-Rust-gateway-trace.txt>` from the repository root. Without `--trace`, only the standalone directed suite runs. Trace commands are `CORE generation`, `GOLDEN independent-payload.bin` (relative to the trace, or absolute), `START epoch fid total crc_hex`, `DMA epoch logical_len aligned_padded_hex`, `COMMIT epoch fid`, `ABORT`. The test compares the first logical bytes against the independent payload and then against actual drained RTL bytes. It ignores and counts backing-buffer padding. Native trace provenance is the native gateway runner's manifest, not this RTL testbench.

Verilator 5.020 with GCC 13.3 is the explicitly selected behavioral backend. The runner uses strict fatal warnings, `--assert`, C++ warnings as errors, a finite cycle watchdog, a 180-second simulation deadline, source snapshots/hashes, tool logs and retained failures. Builds run at most `-j2`, require at least 8 GiB available memory and memory PSI full avg10 below 1, and reject an already active compiler in the shared container. No synthesis, CDC, implementation timing or hardware claim follows from the simulation.
