# Paired cadence phase and drift sensitivity

This isolated analysis compares the nominal ~65 Hz and hypothetical ~60 Hz Verilator cadence traces in `../cadence-study/`. It repeats each trace’s ten measured upload and decode/staging service durations for 1,800 modeled frames. Both clocks receive the same display/source ppm offsets and phase fraction in each paired case. This is an analytical estimate, not a long RTL run or hardware proof.

The default grid has 1,620 paired cases: nine offsets from -1,000 to +1,000 ppm for each clock, with 20 phase offsets per pair. Outputs include finite first-to-last rate, maximum arrival-to-presentation age, arrivals and presentations in a half-open 60-second window, and gap count/duration ranges. A gap is an interval longer than 1.1 modeled source periods; it describes cadence spacing and does not establish frame loss. Ppm values are sensitivity assumptions, not measured tolerances. The model starts each frame no earlier than one cycle after the prior presentation. Arrivals may wait indefinitely behind prior presentations: this is an unbounded hypothetical backlog with no drop queue. Thus long ages depend on that scheduling rule and do not predict a bounded transport queue. The repeated service times ignore changes in content, contention, transport and source behavior.

Reproduce from the repository root:

```sh
python3 fpga/experiments/throughput30/burst/cadence-sensitivity/analyze.py \
  fpga/experiments/throughput30/burst/cadence-study/verilator-65hz.log \
  fpga/experiments/throughput30/burst/cadence-study/verilator-60hz-hypothetical.log \
  --output fpga/experiments/throughput30/burst/cadence-sensitivity/paired-results.json \
  --summary fpga/experiments/throughput30/burst/cadence-sensitivity/SUMMARY.md
python3 -m unittest discover -s fpga/experiments/throughput30/burst/cadence-sensitivity -p 'test_*.py'
```

The checked-in `SUMMARY.md` and `paired-results.json` are generated by that command. They do not prove panel frequency tolerance, MMCM behavior, hardware performance, or sustained 30 displayed fps.
