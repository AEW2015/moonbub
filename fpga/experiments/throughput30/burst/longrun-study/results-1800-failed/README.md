# 1,800-frame register-bus run: strict window failed

The full Verilator behavioral run on 1,800 distinct synthetic JPEG inputs **failed** its strict 60-second capture-window assertion. Every one of the 1,800 ordered frame IDs was eventually presented and each 345,600-pixel framebuffer exactly matched the related fixed-color C model; no modeled drops, queue overflows, or LCD underruns were detected. However, frame 1,800 presented at cycle 6,002,258,520, versus window end 6,002,020,037 at 100 MHz: **2.38483 ms late**. The simulator exited nonzero, the wrapper correctly produced no success summary, and only 1,799 frames appeared before the strict window end. See `failure-tail.log` for the actual assertion.

Across all eventually presented frames, first-to-last cadence was **29.995089 presentations/s** over 1,799 intervals. This is not a pass of the 60-second capture-window criterion. Arrival-to-presentation age p50/p95/p99/max was **28.78737 / 35.70993 / 36.31573 / 36.45743 ms**; 370/1,800 frames exceeded 1/30 second age. `verified.jsonl` records every checked frame and hash; `latency-analysis.json` was generated with `../../latency-study/analyze.py` against the identical retained `../../latency-study/manifest.json` (SHA-256 `0d7a566b5ce380d7f571da198573556f46f377ca5170f74422fbb89a3de445b8`). The analyzer describes its input generically as a prefix; here it contains all 1,800 eventual frames and does **not** override the failed terminal verdict.

This model assumes instantaneous complete JPEG arrivals, a one-frame external queue, and an optimistic two-cycle-per-byte register bus, with a functional SDRAM model. It does not model the QSPI endpoint, Wi-Fi, ESP32 CPU, real memory timing, physical LCD, or actual game capture. The C reference shares decoder algorithms with the RTL. This failure is not an actual hardware measurement; it shows the strict model gate has not been met under these assumptions and phase. Changing phase or display timing must be evaluated as a separate experiment, with panel support and actual clock behavior unverified.
