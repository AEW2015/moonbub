This standalone offline component combines the BRAM gather, eight-block transpose, canonical byte/word and HUD stages, constant HC bounds, and registered child cancel. Python helpers require only the standard library plus Icarus Verilog/vvp on PATH (or IVERILOG/VVP environment variables). No other GameBub checkout is needed.

Run `python verify.py` for exact local sources and historical report bindings.
